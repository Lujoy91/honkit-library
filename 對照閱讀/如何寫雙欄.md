# 雙欄語法說明

## 基本寫法

在 Markdown 裡直接寫這四個註解標記就好，**裡面照常寫 Markdown**：

```
<!--dual-->
<!--src-->

English paragraph one.

<!--tgt-->

中文第一段。

<!--src-->

English paragraph two.

<!--tgt-->

中文第二段。

<!--/dual-->
```

## 自訂欄位標題

`<!--dual 左邊標題|右邊標題-->`，例如：

```
<!--dual 🇬🇧 English|🇹🇼 中文翻譯-->
```

不寫的話預設是「原文 / 中文翻譯」。

## 規則

1. `<!--src-->` 和 `<!--tgt-->` 要**成對輪流出現**，一段原文配一段翻譯。
2. 每一組 src / tgt 會自成一列，左右自動對齊。段落切得越細，對齊越好讀。
3. 標記前後要有空行。
4. 裡面可以用粗體、清單、程式碼、連結等所有 Markdown 語法。
5. 手機上會自動變成「原文 → 翻譯 → 原文 → 翻譯」上下交錯。
6. 頁面上方會有「對照 / 只看原文 / 只看翻譯」三顆切換鈕。

## ⚠️ 為什麼不能直接用 `<div>`

HonKit 的 Markdown 解析器**不會處理 HTML 標籤裡面的 Markdown**。
直接寫 `<div class="dual">` 包住內容，裡面的 `**粗體**`、段落、清單全部都會變成純文字，
而且最後一個 `</div>` 還會被當成文字印出來。這就是之前卡住的原因。
用註解標記可以避開這個問題 —— Markdown 先正常解析完，外掛才在事後把註解換成 `<div>`。
